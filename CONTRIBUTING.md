# Contributing

OpenAgent Studio welcomes genuine contributions.

## Development
Requires Python 3.10+ and no external packages.

```bash
python -m openagent demo
python -m unittest discover -s tests -v
```

Fork the project, create a focused branch, include tests and open a pull request explaining the change.

## Good first issues
- Validate and serialize workflow definitions
- Add a JSON-driven CLI
- Improve event log persistence
- Add accessible dashboard prototypes
- Add tests for invalid workflow states

Do not commit credentials, private data or customer records. Never submit artificial pull requests to inflate activity. Report security concerns privately to the maintainer.
